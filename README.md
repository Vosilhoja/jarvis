# 🤖 Jarvis — Персональный Telegram-ассистент для Windows

Полнофункциональный локальный ассистент на Python для управления компьютером на базе Windows через Telegram-бота с интеграцией **Google Gemini 2.5**, пультом дистанционного управления (мышь/клавиатура), менеджером процессов, созданием скриншотов с поддержкой нескольких экранов, защитой доступа и фоновым автозапуском.

---

## ✨ Возможности

- **Строгая безопасность:** Доступ разрешён строго одному Telegram ID (`ALLOWED_USER_ID`). Все остальные запросы отклоняются с фиксацией в логе.
- **Интуитивное Inline-меню:** Удобное управление всеми функциями в 2 клика:
  - 📸 **Скриншот:** Снимок всего рабочего стола или выбор конкретного монитора (Монитор 1, 2, 3...).
  - 🖥 **Инфо о системе:** Загрузка процессора (CPU), оперативной памяти (RAM), свободное место на всех дисках и время работы ПК (uptime).
  - 🔒 **Блокировка экрана:** Мгновенная блокировка рабочей станции Windows.
  - 😴 **Спящий режим:** Перевод ПК в энергосберегающий спящий режим.
  - 🔁 **Перезагрузка и ⛔ Выключение:** Безопасное выключение/перезагрузка с диалогом подтверждения и 30-секундным таймером отмены.
  - 📋 **Диспетчер процессов:** Просмотр процессов по RAM/CPU и возможность принудительного завершения любого процесса по кнопке или команде `/kill <PID>`.
  - 🖱 **Удалённое управление:** Кнопки перемещения курсора, левый/правый/двойной клик, скролл.
  - 📁 **Файловый менеджер:** Навигация по рабочему столу и возможность скачивания файлов прямо в Telegram.
  - 🤖 **Интеграция с Gemini AI:** Свободные текстовые вопросы без команд передаются в модель Google Gemini с сохранением контекста последних ~10 сообщений.
- **Текстовые команды прямого управления:**
  - `mouse: 800,600` — мгновенно переместить курсор в координаты X, Y.
  - `click` / `rclick` / `dclick` — клик левой / правой / двойной клик.
  - `type: Привет мир` — ввод текста в активное окно (с полной поддержкой русского языка через буфер обмена).
  - `key: win+d` или `key: ctrl+c` — нажатие комбинаций и горячих клавиш.
  - `scroll: 400` / `scroll: -400` — прокрутка колеса мыши вверх или вниз.
- **Отказоустойчивость (Watchdog):** Скрипт-нянька `watchdog.py` автоматически перезапускает бота при сбоях или отключении интернета.
- **Автозапуск Windows:** Готовый PowerShell-скрипт для Планировщика заданий Windows, запускающий Jarvis без лишних консольных окон при входе в систему.

## 🚀 Пошаговая инструкция по установке

### 1. Установка Python
Убедитесь, что у вас установлен Python версии **3.11 или новее**:
1. Скачайте Python с [официального сайта python.org](https://www.python.org/downloads/).
2. **ВАЖНО:** Во время установки обязательно отметьте галочку **«Add Python to PATH»** (Добавить Python в переменные среды).

### 2. Клонирование или переход в папку проекта
Откройте терминал PowerShell или Командную строку:
```powershell
cd C:\Users\<Ваш_Пользователь>\Desktop\jarvis
```

### 3. Создание виртуального окружения (рекомендуется)
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```
*(Если PowerShell блокирует выполнение скриптов, выполните один раз: `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass`)*

### 4. Установка зависимостей
```powershell
pip install --upgrade pip
pip install -r requirements.txt
```

## ⚙️ Настройка конфигурации (`.env`)

1. Скопируйте файл `.env.example` в `.env`:
   ```powershell
   Copy-Item .env.example .env
   ```
2. Откройте файл `.env` в Блокноте или любом редакторе:
   ```env
   TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrSTUvwxyz
   GOOGLE_API_KEY=AIzaSy...Ваш_Ключ_Gemini...
   ALLOWED_USER_ID=987654321
   ```

### Где взять эти значения:
1. **`TELEGRAM_BOT_TOKEN`**:
   - Напишите боту [@BotFather](https://t.me/BotFather) в Telegram.
   - Отправьте команду `/newbot`, укажите имя и username для бота.
   - Скопируйте выданный токен API.
2. **`GOOGLE_API_KEY`**:
   - Перейдите в [Google AI Studio](https://aistudio.google.com/app/apikey).
   - Войдите в Google-аккаунт и нажмите **Create API key**.
   - Скопируйте сгенерированный ключ.
3. **`ALLOWED_USER_ID`**:
   - Напишите боту [@userinfobot](https://t.me/userinfobot) в Telegram.
   - Он пришлет ваш числовой ID (например: `123456789`). Укажите именно его.

## 🎮 Ручной запуск и проверка

### Прямой запуск:
```powershell
python main.py
```

### Запуск с Watchdog (рекомендуется):
```powershell
python watchdog.py
```
Watchdog запустит бота и, если бот внезапно завершится (например, обрыв сети), автоматически поднимет его заново через несколько секунд.

Теперь откройте вашего бота в Telegram и отправьте команду:
```
/start
```
Перед вами откроется главное меню с кнопками управления.

## ⏰ Настройка автозапуска при включении Windows

Чтобы Jarvis работал всегда, когда включён компьютер, и стартовал автоматически без отображения чёрных окон консоли:

1. Откройте **PowerShell от имени Администратора** (кликните правой кнопкой мыши по меню «Пуск» ➔ «Терминал (Администратор)» или «Windows PowerShell (Администратор)»).
2. Перейдите в папку проекта:
   ```powershell
   cd C:\Users\<Ваш_Пользователь>\Desktop\jarvis
   ```
3. Запустите скрипт установки:
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\autostart\install_task.ps1
   ```

Скрипт автоматически найдёт `pythonw.exe` (версия Python без окна консоли), настроит задачу в Планировщике заданий Windows (`Task Scheduler`) с наивысшими правами и автозапуском при входе в систему.

### Удаление из автозапуска:
Если вам потребуется отключить автозапуск, запустите в PowerShell от Администратора:
```powershell
powershell -ExecutionPolicy Bypass -File .\autostart\uninstall_task.ps1
```

## 🛡 Безопасность

- **FailSafe экстренной остановки:** В коде активирован `pyautogui.FAILSAFE = True`. Если мышь начнёт вести себя непредсказуемо, просто резко дерните физическую мышь рукой в любой крайний угол экрана (например, верхний левый угол `0,0`) — это немедленно прервёт выполнение операций манипуляции курсором.
- **Защита от случайного выключения:** Кнопки перезагрузки и выключения всегда запрашивают подтверждение, а после нажатия выставляют 30-секундный таймер с возможностью отмены одной кнопкой прямо из Telegram.
- **Ограничение прав:** Никто, кроме пользователя с `ALLOWED_USER_ID`, не сможет выполнить ни одной команды или получить доступ к файлам и снимкам экрана.
