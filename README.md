# 🤖 JARVIS — Персональный резидентный ИИ-агент и оператор ПК (Windows 10/11)

Репозиторий: https://github.com/Vosilhoja/jarvis.git  
ОС: Windows 10/11  
Канал управления: Telegram (текст и голос), long polling  

Jarvis — это не просто бот с командами, а **резидентный автономный ИИ-ассистент**, который понимает свободную человеческую речь, сам разбивает сложные многозадачные фразы на упорядоченные цепочки шагов, находит приложения даже при сильных опечатках и сленге, проактивно следит за здоровьем системы и выполняет задачи непрерывно в фоне.

---

## 🌟 Ключевые возможности

1. **🧠 Интеллектуальный "Мозг" и цепочки задач (Multi-step Execution):**
   - Понимание сложных составных поручений одной фразой:
     > _«Перейди в 1 рабочий стол, открой яндекс музыку, сделай скриншот»_
   - Автоматическое накопление и исполнение последовательных сообщений в рамках диалога:
     > _«И потом открой проводник, перейди по пути рабочего стола, создай папку Проект и с википедии загрузи сюда статью про космос»_
   - Пошаговые отчеты в Telegram по факту каждого выполненного действия.

2. **🔍 Умный ИИ-поиск приложений (App Resolver):**
   - Никаких жестких совпадений имён!
   - Двухступенчатый поиск: быстрый нечеткий fuzzy-анализ (`rapidfuzz`) + арбитраж нейросетью Google Gemini.
   - Понимает сленг, сокращения и опечатки: «яндекс музыка», «янд музыка», «ymusic», «музыка от яндекса», «хром», «стим», «vs code», «блокнот», «калькулятор».

3. **🎤 Голосовое управление (Speech-to-Text):**
   - Поддержка голосовых сообщений Telegram.
   - Распознавание через Gemini Multimodal STT с поддержкой смешанной русско-английской речи (названия программ и термины).

4. **🎛 Полный контроль над Windows:**
   - **Виртуальные рабочие столы:** мгновенное переключение по номерам (1, 2, 3...) и создание новых.
   - **Звук и медиа:** изменение громкости, Mute, Play/Pause, Next/Prev трек.
   - **Файлы и Проводник:** создание папок, файлов, открытие путей, понимание алиасов («рабочий стол», «загрузки», «документы»).
   - **Википедия и Веб:** поиск информации, скачивание статей в `.txt` прямо в указанные папки.
   - **Безопасность:** опасные действия (удаление файлов, выключение ПК, принудительный kill) запрашивают обязательное подтверждение через inline-кнопки (Да/Нет).

5. **⏰ Напоминания и фоновый мониторинг (Scheduler & Watchdog):**
   - Напоминания на естественном языке («напомни через 20 минут проверить отчет»). Хранятся в `data/reminders.json` и переживают перезагрузку ПК.
   - Проактивные предупреждения о нехватке места на диске (< 10 ГБ), высокой нагрузке CPU/RAM и зависших окнах (`IsHungAppWindow`).
   - Ежедневная утренняя сводка в 09:00 о самочувствии компьютера.
   - Супервизор `watchdog.py` для автоматического перезапуска при сбоях.

## 📁 Структура проекта

```
jarvis/
├── core/
│   ├── intent_schema.py        # Единый реестр intent'ов, Pydantic валидация (source of truth)
│   ├── app_resolver.py         # Индексация ПО (Start Menu, Registry, PATH) + Fuzzy/ИИ поиск
│   ├── task_queue.py           # Очередь шагов и контекст сессии пользователя
│   └── executor.py             # Пошаговый исполнитель очереди с отчетами
├── handlers/
│   ├── auth.py                 # Проверка белого списка ALLOWED_TELEGRAM_USER_IDS
│   ├── voice.py                # Обработка голосовых сообщений
│   ├── menu.py                 # Главное меню, виртуальные столы, медиа, подтверждения
│   ├── remote_control.py       # Маршрутизация текстовых команд и мыши/клавиатуры
│   ├── process_commands.py     # Диспетчер процессов и kill
│   ├── system_commands.py      # Выключение, сон, блокировка, скриншоты
│   ├── files.py                # Файловый браузер рабочего стола
│   └── ai_chat.py              # Диалог с ИИ и очистка истории
├── services/
│   ├── ai_client.py            # Вызов Gemini API, структурированный JSON план
│   ├── stt_client.py           # Распознавание голоса через Gemini Multimodal
│   ├── desktops_control.py     # Управление виртуальными рабочими столами
│   ├── media_control.py        # Громкость (pycaw), яркость, мультимедиа-клавиши
│   ├── web_client.py           # Веб-поиск, статьи Wikipedia, погода, курсы валют
│   ├── system_monitor.py       # Пороги здоровья ПК, зависшие окна, очистка %TEMP%
│   ├── system_info.py          # Метрики CPU/RAM/дисков
│   ├── screenshot.py           # Скриншоты с поддержкой нескольких экранов
│   └── notifier.py             # Централизованные уведомления с антиспамом
├── autostart/
│   ├── install_task.ps1        # Регистрация в Планировщике заданий Windows
│   └── uninstall_task.ps1
├── data/                       # Хранилище кэша ПО и напоминаний
├── scheduler.py                # Фоновый мониторинг и планировщик
├── watchdog.py                 # Перезапуск при сбоях
├── main.py                     # Точка входа бота
├── requirements.txt
├── .env.example
└── README.md
```

## 🚀 Установка и настройка

### 1. Установка зависимостей
```powershell
pip install -r requirements.txt
```

### 2. Настройка `.env`
Скопируйте шаблон:
```powershell
Copy-Item .env.example .env
```
Заполните обязательные поля в файле `.env`:
```env
TELEGRAM_BOT_TOKEN=ваш_токен_бота
GOOGLE_API_KEY=ваш_ключ_google_ai_studio
ALLOWED_TELEGRAM_USER_IDS=ваш_telegram_id
```

### 3. Запуск

- **Ручной запуск:**
  ```powershell
  python main.py
  ```
- **Запуск с супервизором Watchdog (рекомендуется для постоянной работы):**
  ```powershell
  python watchdog.py
  ```
- **Автозапуск вместе с Windows:**
  Запустите PowerShell от имени Администратора:
  ```powershell
  powershell -ExecutionPolicy Bypass -File .\autostart\install_task.ps1
  ```

## 💬 Примеры команд

- 🎤 **Голосом:** просто зажмите микрофон и скажите: _«Привет, переключи на второй рабочий стол и сделай скриншот экрана»_.
- 💻 **Многошаговые цепочки:** _«Открой проводник, создай на рабочем столе папку Отчеты и скачай с википедии статью про искусственный интеллект»_.
- 🎵 **Медиа:** _«Сделай потише»_, _«Включи следующий трек»_, _«Поставь на паузу»_.
- ⏰ **Напоминания:** _«Напомни через 30 минут выпить воды»_.
- 🧹 **Очистка:** _«Очисти временные файлы»_.
- 🌤 **Быстрые запросы:** _«Какая погода?»_, _«Какой курс доллара?»_.
