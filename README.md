# Jarvis AI — локальный Telegram-оператор Windows

[![Platform](https://img.shields.io/badge/platform-Windows%2010%2F11-0078D4)](https://www.microsoft.com/windows)
[![Python](https://img.shields.io/badge/Python-3.12%2B-3776AB)](https://www.python.org/)
[![Telegram](https://img.shields.io/badge/control-Telegram-26A5E4)](https://telegram.org/)
[![License](https://img.shields.io/badge/license-private-lightgrey)](https://github.com/Vosilhoja/jarvis)

Jarvis — персональный Telegram-бот для локального управления компьютером на Windows. Он принимает текстовые и голосовые команды, понимает естественный язык, выполняет простые действия напрямую, а сложные запросы разбивает на проверяемые шаги.

Проект рассчитан на **одного владельца ПК**: доступ ограничивается Telegram ID, опасные операции требуют подтверждения, а локальное состояние хранится в файлах проекта.

> Важно: Jarvis может управлять окнами, файлами, громкостью, рабочими столами и питанием Windows. Запускайте его только на личном компьютере и не добавляйте в whitelist неизвестных пользователей.

## Возможности

### Команды и локальный ИИ

- естественные русскоязычные команды и свободный диалог;
- быстрые rule-based команды без обращения к модели;
- многошаговые сценарии с отчётом по каждому шагу;
- распознавание опечаток и названий приложений через fuzzy-поиск;
- локальная память: история intent'ов, успешные действия и shortcuts;
- ограниченные retry, cooldown и кэш модели для меньшей нагрузки;
- Gemini используется для планирования и голосового распознавания, если это включено в конфигурации.

### Управление Windows

- виртуальные рабочие столы: переход, создание и удаление с проверкой результата;
- громкость, mute, медиаклавиши, яркость и звук отдельных приложений;
- запуск приложений, поиск программ и управление окнами;
- горячие клавиши и безопасный пульт мыши;
- скриншоты экрана и виртуальных рабочих столов;
- системная информация: CPU, RAM, диски, температура, батарея, процессы;
- проводник, рабочий стол, загрузки, документы и поиск файлов;
- IP, адаптеры, Wi-Fi, ping, traceroute, DNS и `ipconfig`;
- Defender, Firewall, USB, принтеры и другие системные инструменты.

### Напоминания и фоновые задачи

- напоминания: `через 20 минут проверить почту`, `сегодня в 18:30 позвонить`;
- сохранение активных напоминаний между перезапусками;
- фоновый мониторинг CPU, RAM, температуры, дисков и зависших окон;
- утренний брифинг и планировщик задач;
- watchdog для перезапуска бота после сбоя.

## Архитектура

```text
jarvis/
├── main.py                     # Запуск Telegram-приложения
├── watchdog.py                 # Контролируемый перезапуск
├── scheduler.py                # Напоминания и фоновые проверки
├── config.py                   # Настройки из окружения
├── domain/                     # Чистая бизнес-логика без Telegram/Windows
│   ├── memory.py               # Память, shortcuts и контекст
│   ├── tasks.py                # Задачи пользователя
│   └── storage/json_store.py   # Атомарное потокобезопасное JSON-хранилище
├── core/                       # Intent'ы, планирование и выполнение
│   ├── intent_schema.py        # Реестр intent'ов и Pydantic-модели
│   ├── executor.py             # Исполнитель шагов
│   ├── task_queue.py           # Очередь и сессии задач
│   └── execution/              # Исполнители файлов, системы, задач
├── adapters/windows/           # Изолированные Windows-интеграции
│   ├── files.py
│   ├── input.py
│   ├── security_tools.py
│   ├── system_utilities.py
│   └── window_manager.py
├── handlers/                   # Telegram handlers и маршрутизация меню
│   └── menu/                   # Категории клавиатуры и их routers
├── services/                   # Внешние сервисы и совместимые фасады
├── security/                   # Политики риска и подтверждения
├── tests/                      # Безопасные тесты
├── autostart/                  # Task Scheduler scripts
├── data/                       # Локальное runtime-состояние, не для Git
└── requirements.txt
```

Главный принцип: Telegram-слой только принимает запрос и показывает результат, доменная логика не зависит от Telegram, а Windows-вызовы находятся в `adapters/windows`. Долгие синхронные операции выносятся из event loop через `asyncio.to_thread`.

## Требования

- Windows 10 или Windows 11;
- Python 3.12 или новее;
- Telegram-бот, созданный через [@BotFather](https://t.me/BotFather);
- Telegram ID владельца;
- Google AI Studio API key — для Gemini/STT-функций;
- PowerShell и стандартные Windows-команды;
- интернет только для функций, которым он нужен: Gemini, Wikipedia, публичный IP и speed test.

Некоторые действия требуют прав Windows или наличия оборудования. Например, температура CPU, яркость и подсветка клавиатуры могут быть недоступны на конкретном ПК.

## Установка

Откройте PowerShell в каталоге проекта:

```powershell
cd C:\Users\<user>\Desktop\jarvis
```

Создайте виртуальное окружение. Не используйте `C:\Windows\System32\python` — это системная заглушка, а не интерпретатор проекта:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Если PowerShell блокирует активацию:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

Для `pywin32` при необходимости выполните:

```powershell
python .\.venv\Scripts\pywin32_postinstall.py -install
```

## Конфигурация

Скопируйте шаблон и заполните его:

```powershell
Copy-Item .env.example .env
notepad .env
```

Минимальная конфигурация:

```env
TELEGRAM_BOT_TOKEN=replace_with_botfather_token
GOOGLE_API_KEY=replace_with_google_ai_studio_key
ALLOWED_TELEGRAM_USER_IDS=123456789
```

Полезные настройки:

| Переменная | Назначение |
|---|---|
| `AI_MODEL_NAME` | Основная Gemini-модель |
| `AI_FALLBACK_MODEL_NAME` | Резервная модель |
| `AI_MAX_STEPS_PER_MESSAGE` | Максимум шагов одного сценария |
| `AI_TEMPERATURE` | Температура генерации |
| `APPS_SCAN_PATHS` | Дополнительные каталоги поиска приложений |
| `APPS_CACHE_TTL_HOURS` | Время жизни кэша приложений |
| `BACKGROUND_CHECK_INTERVAL_SEC` | Интервал фоновой диагностики |
| `DISK_FREE_THRESHOLD_GB` | Порог свободного места |
| `CPU_LOAD_THRESHOLD_PERCENT` | Порог предупреждения CPU |
| `RAM_LOAD_THRESHOLD_PERCENT` | Порог предупреждения RAM |
| `TEMP_THRESHOLD_CELSIUS` | Порог предупреждения температуры |
| `STT_PROVIDER` / `STT_LANGUAGE` | Провайдер и язык распознавания голоса |

Никогда не коммитьте `.env`, токены, OAuth-файлы Google или runtime JSON. Они уже исключены из Git правилами `.gitignore`.

## Запуск

Однократный запуск:

```powershell
.\.venv\Scripts\python.exe .\main.py
```

Запуск с watchdog:

```powershell
.\.venv\Scripts\python.exe .\watchdog.py
```

Остановка: нажмите `Ctrl+C` в окне процесса. Не запускайте два экземпляра с одним Telegram-токеном — Telegram разрешает только один активный polling-процесс. В проекте есть single-instance lock, но лучше также проверять старый процесс перед повторным запуском.

Автозапуск через Windows Task Scheduler:

```powershell
powershell -ExecutionPolicy Bypass -File .\autostart\install_task.ps1
```

Удаление автозапуска:

```powershell
powershell -ExecutionPolicy Bypass -File .\autostart\uninstall_task.ps1
```

## Категории Telegram-меню

Клавиатура разделена на независимые категории:

- **Система** — диагностика, диски, батарея, питание и мониторинг;
- **Медиа / Звук** — громкость, mute и медиаклавиши;
- **Файлы** — проводник, папки, поиск по имени и содержимому;
- **Сеть** — IP, Wi-Fi, ping, traceroute, DNS и скорость;
- **Приложения** — быстрый запуск и поиск установленного ПО;
- **Управление ПК** — горячие клавиши, рабочие столы и пульт мыши;
- **Скриншот** — экран и отдельные виртуальные столы;
- **Инструменты** — QR, пароль, Defender, Firewall, USB и принтеры;
- **Напоминания** и **ИИ-чат** — отдельные режимы общения.

Все кнопки проходят через соответствующий router. Если операция опасная, бот должен показать inline-подтверждение, а не сообщать об успехе заранее.

## Безопасная проверка без воздействия на ПК

Во время разработки не запускайте `main.py`, `watchdog.py`, polling, реальные Windows-команды, pyautogui, сетевые тесты или Ollama/Gemini без необходимости.

Статические проверки:

```powershell
.\.venv\Scripts\python.exe -m compileall -q .
.\.venv\Scripts\python.exe -m ruff check .
git diff --check
```

Тесты запускайте только в отдельном безопасном окружении и только после проверки, что они не отправляют Telegram-запросы и не управляют мышью/клавиатурой:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

## Производительность и надёжность

- простые действия не требуют вызова ИИ;
- фоновые проверки разделены по стоимости и выполняются с интервалами;
- долгие операции не блокируют Telegram event loop;
- локальное JSON-хранилище атомарное и защищено от параллельной записи;
- запросы к AI ограничены retry и cooldown;
- результаты системных действий проверяются фактически, чтобы не было ложного «Выполнено»;
- повторяющиеся команды могут сохраняться как shortcuts, но повторно проходят policy-проверки;
- одновременно допускается обработка разных чатов, а команды одного пользователя сохраняют порядок.

## Диагностика проблем

### `Conflict: terminated by other getUpdates request`

Запущено больше одного polling-процесса. Остановите старые экземпляры Jarvis и запустите только один `main.py` или один `watchdog.py`.

### Бот отвечает, но действие не выполняется

1. Проверьте, что команда попадает в нужную категорию меню.
2. Проверьте права Windows и доступность оборудования.
3. Посмотрите `jarvis.log` и `watchdog.log` локально.
4. Не считайте сообщение об успехе доказательством: системные действия должны подтверждаться кодом возврата или повторной проверкой состояния.

### Не работают голосовые команды

Проверьте `GOOGLE_API_KEY`, `STT_PROVIDER`, `STT_LANGUAGE`, интернет и размер голосового сообщения.

### Не запускается приложение

Пересоздайте кэш приложений и проверьте `APPS_SCAN_PATHS`. Не добавляйте в `.env` пути с неподтверждёнными правами доступа.

## Разработка

Перед изменением кода:

1. Сначала ищите существующий adapter/service, а не добавляйте новый дубликат.
2. Не помещайте Windows-вызовы в Telegram handlers.
3. Для новой команды добавляйте intent, policy, executor и router, если они нужны.
4. Учитывайте dry-run и не запускайте реальные действия в тестах.
5. Проверяйте компиляцию, Ruff и `git diff --check`.

Полезные документы:

- [`CHANGES.md`](./CHANGES.md) — история изменений;
- [`PATCH_NOTES.md`](./PATCH_NOTES.md) — заметки по исправлениям;
- [`AGENT_RULES.md`](./AGENT_RULES.md) — правила разработки;
- [`docs/`](./docs/) — дополнительные материалы.

## Ограничения

- проект поддерживает Windows 10/11 и не является кроссплатформенным;
- часть функций зависит от конкретного оборудования и драйверов;
- Gemini-функции требуют API key и могут расходовать квоту;
- Telegram long polling требует единственного активного экземпляра;
- Jarvis не является антивирусом и не заменяет резервное копирование;
- автоматическое «саморазвитие» ограничено безопасными shortcuts, памятью контекста и статистикой — код самопроизвольно не переписывается.

## Лицензия и ответственность

Репозиторий предназначен для личного использования. Перед публикацией или передачей проекта добавьте явную лицензию и проверьте сторонние зависимости. Автор запускает команды Jarvis на свой риск и должен заранее ограничить Telegram ID владельца.
